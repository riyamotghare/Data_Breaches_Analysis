# Data Breach Analysis by Industry

## About
Analysis of global data breaches across industries using Python.

## Dataset
- Source: Kaggle — "Data Breaches" by The Devastator
- File: df_1.csv
- Records: 351 rows, 6 columns

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Topics Covered
- Data Cleaning
- Data Wrangling
- Exploratory Data Analysis (EDA)
- Data Visualization

## How to Run
1. Open the .ipynb file in Google Colab
2. Upload df_1.csv when prompted
3. Run all cells from top to bottom
